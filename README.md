# Modular Satellite Ground Station & RF Experimentation Platform

A student-led, modular ground station and RF experimentation platform developed to receive, process, and analyze VHF signals (targeting the 137 MHz weather satellite band) using Software-Defined Radios (SDRs) and custom-built antennas[cite: 2, 3]. 

---

## 🏗️ System Architecture
The platform utilizes a modular architecture to independently test, troubleshoot, and characterize individual antennas, SDR hardware platforms, and digital signal-processing tools before full integration[cite: 2, 3].
